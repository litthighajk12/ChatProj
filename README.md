# ChatProj

A C++ MFC-based client-server chat application.

## Projects

### ChatProjClient
MFC desktop client application.

### Chatserver
C++ backend server using Winsock and IOCP.

## Technologies

- C++
- MFC
- Winsock TCP/IP
- IOCP
- Apache Kafka
- Memurai / Redis
- SQL Database

## Development Environment

- Windows
- Visual Studio 2026
- C++ Desktop Development workload

## How to Open

1. Clone this repository.
2. Open Chatserver/Chatserver.slnx in Visual Studio.
3. Configure the required external dependencies.
4. Build the projects.
